# Wireframes · Fase 1

Telas da issue #8, desenhadas no artefato de Design do Claude:
<https://claude.ai/artifact/GSJ624Xtfo4j2VYPsQrSeK>

Cada tela tem versão para computador (1280 px) e celular (390 px), conforme o RNF01.

| Arquivo | Tela |
| :--- | :--- |
| `01-estilo-visual.png` | Cores, fontes, botões, campos, cartão de animal e avisos |
| `02-menu-computador.png` | Cabeçalho e menu: sem login, adotante e responsável |
| `03-menu-celular.png` | Menu do celular aberto nas três situações |
| `04-inicio-computador.png` · `05-inicio-celular.png` | Tela inicial |
| `06-login-computador.png` · `07-login-celular.png` | Login |
| `08-cadastro-computador.png` · `09-cadastro-celular.png` | Cadastro com escolha do tipo de conta |

Os campos do cadastro seguem o modelo `usuarios.Usuario`: nome, email, telefone (opcional), senha e tipo (adotante ou responsável).
Textos entre colchetes, como `[Nome]`, são espaços para dados reais.
